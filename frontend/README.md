# 💰 Expense Tracker — Frontend Client

This directory contains the client-side single-page application (SPA) built with **React 19**, **Vite 8**, **React Router DOM v7**, **Recharts**, and **Lucide Icons**.

For complete project documentation, architecture diagram, full API endpoint references, environment variables, and setup instructions, please refer to the main repository documentation:

👉 **[Root README.md](../README.md)**

---

## 🚀 Quick Start (Frontend)

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Production build
npm run build

# 4. ESLint verification
npm run lint
```

- **Dev Server**: `http://localhost:5173/` (or `5174` if 5173 is busy)
- **Backend API Proxy / Base URL**: `http://localhost:5000/api`
